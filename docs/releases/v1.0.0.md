# OMP Switch v1.0.0

This release starts the 1.0 line with a current OMP compatibility baseline, guarded snapshot recovery in the CLI, and regression coverage for the Windows and Linux packaged CLI paths.

## Added

- **Guarded snapshot restore in the JSON CLI.** `restore --profile <name> --snapshot <id>` uses the same guarded adapter as the GUI; it refuses to overwrite files changed after the snapshot. `--force` is an explicit override. The TUI also exposes restore as a non-interactive command for scripts.
- **OMP v18.8 settings contract.** Added types and validation for per-model compaction thresholds, the threshold enable switch, usage-reset waits, usage-aware fallback and reserve policy fields. Added the built-in `judge` model role and matching English/Chinese UI labels.
- **Field-level OMP schema drift watch.** A pinned v18.8.7 source baseline accompanies the existing major-version check. Changes within a writable major raise a review signal; they do not automatically enable compatibility.
- **Packaged CLI recovery tests.** Linux CI and the Windows package verification script now cover snapshot → edit → guarded refusal → explicit forced restore.

## Changed

- Updated the compatibility audit to Oh My Pi v18.8.7 and the CC Switch feature reference to v4.0.6. CC Switch remains a source of UX ideas, not a target for multi-CLI OAuth/account management or cloud sync.
- Updated the CLI installation and feature documentation to list all JSON commands and explain restore and secret masking behavior.

## Security

- Restore uses the existing snapshot path validation and hash guard; it does not create a separate file-writing path.
- CLI restore results use the existing secret-masking helper. `get --reveal-secrets` remains an explicit opt-in.
- No new runtime dependency was added. No OMP `agent.db`, OAuth refresh token, or project-local `.omp` overlay is read or modified.

## Known Limitations

- `compaction.modelThresholds` and usage-aware retry fields are typed, validated, and preserved, but are not fully editable in the GUI.
- Provider connectivity checks and the broader multi-CLI routing/quotas features of CC Switch are not part of this release.
- Gateway remains local and user-triggered; OMP OAuth integration remains limited to status/login entry points and does not manage refresh tokens; session indexing is local-only; update checking depends on the signed manifest secret.
- GUI release artifacts target Windows x64 and Linux x64. Installers remain unsigned; verify checksums and provenance.
- WinGet submissions require upstream review. Chocolatey publication requires a valid feed submission and moderation. The GHCR package may require its visibility to be changed to public in repository package settings.
