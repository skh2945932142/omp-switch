# OMP Switch v0.2.0

## Added

- OMP v16/v17 configuration support, Profiles, snapshots, conflict protection, and legacy migration confirmation.
- Versioned provider catalog, six discovery modes, compact Provider/Model workbench, Prompts, Skills, Sessions, and Gateway modules.
- Native console JSON CLI launcher, Windows DPAPI secret bridge, OMP OAuth status/login, and guided OMP update command.

## Changed

- Provider, model, role, and settings validation follows the current documented OMP fields.
- Project `.omp` configuration is visible and copyable but remains read-only.

## Security

- API keys stay in the OS-backed vault; session raw content is read on demand and is excluded from metadata and default exports.
- Gateway pool, upstream, and credential identifiers are validated before storage.

## Fixed

- OMP v17 installations are no longer downgraded to read-only by the legacy version gate.
- Role selectors preserve slash-heavy model IDs and thinking suffixes.
- The portable build is an unpack-and-run ZIP so JSON CLI stdout remains available to scripts.

## Known limitations

- No cloud sync, tray switching, automatic account rotation, or signed in-app updates.
- A maintainer must review the GitHub Release draft, checksums, provenance, and clean-Windows install results before publication.
