# OMP Switch v0.4.5

This release adds renderer internationalization. The UI that shipped as Simplified Chinese
only now switches between 中文 and English from the top bar, follows the OS language when
asked, and paints the first frame in the stored language instead of flashing Chinese.

i18n is renderer-only: catalogs are statically inlined, there is no HTTP backend and no
IPC, and Chinese remains the fallback so a missing English key never renders as a raw key.
The write path, secret bridge, gateway, and update checker are unchanged.

## Added

- **Renderer i18n** (i18next + react-i18next). Every chrome string is keyed in
  `src/renderer/i18n/locales/{zh,en}.json` (465 keys; interpolations aligned and locked by
  `locales.test.ts`). The top bar gains a language switch — 中文 / English / 跟随系统 —
  persisted as `omp.locale`. `system` follows `navigator.language` (`zh*` → zh, otherwise
  en) and a `languagechange` listener re-applies when the OS language changes.
- **First-paint locale.** `i18n.init` reads `omp.locale` synchronously (`initAsync: false`)
  and `index.html` sets `<html lang>` before React mounts, so an English user never sees a
  Chinese flash on launch.

## Changed

- Surfaces empty CTA interpolates the surface label (`surfaces.newWithLabel`) instead of
  concatenating `t("surfaces.new")` with the English kind name.
- Surfaces delete confirmation uses `ConfirmDialog` (`window.confirm` is banned).
- Gateway credential field layout keys off `.upstream-credential`, not a localized
  placeholder.

## Fixed

- English `providerEditor.providerIdUrlRequired` no longer inverts the check
  (`!id || !url` is "cannot be empty", not "cannot both be empty").
- Roles dirty-dot tooltip no longer interpolates `roles.dirtyCount` with `count: 0`.
- Browser-preview mock diagnostics are translated at `get()` time so a language switch
  does not freeze them in Chinese.

## Feature status

- **Update checking**: implemented (v0.4.4). Ed25519-signed manifest fetched from GitHub,
  signature verified against a hardcoded key, throttled to 24h, silent on failure,
  auto-check on by default with a manual toggle. Only notifies; never auto-downloads or
  installs. Unchanged in this release.
- **Gateway**: experimental, headless only (`--gateway [profile]`), loopback with a
  mandatory bearer token; unchanged.
- **OAuth integration**: passthrough to `omp auth status` / `omp auth login` only; no
  token storage or refresh handling in-app; unchanged.
- **Session indexing**: always on — two-phase incremental refresh backed by the on-disk
  metadata cache; unchanged.

## Known limitations

- Demo session titles / chat in `createMockApi` stay Chinese: they are fixture content,
  not chrome. `KNOWN_ROLES` keeps its Chinese gloss as a fallback for the export
  contract; the displayed gloss comes from `roles.roleGloss.*`.
- Usage in-row sparkline stays labelled as cost (`usage.dailyTrend`) because that series
  is always `bucketCost`.
- The desktop application is Windows-only because its credential path uses Windows DPAPI.
- The binaries are not code-signed, so SmartScreen can warn on first run.
- Mica requires Windows 11 22H2+ and falls back to solid surfaces elsewhere; the custom
  title bar requires Windows 10+ and falls back to the system frame elsewhere.
- winget and Chocolatey submissions remain pending in their external review queues.
