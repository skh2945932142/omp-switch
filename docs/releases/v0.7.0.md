# OMP Switch v0.7.0

**Aligned with Oh My Pi v18.2.** This release tracks upstream's provider catalog and routing schema — the fallback-chain editor is the headline — and adds an RPM package for Fedora/RHEL/openSUSE. The nightly Windows install regression, broken since its introduction in v0.6.0, is fixed.

## Added

- **Fallback-chain editor** for OMP v18 `retry.fallbackChains`: a JSON editor in the settings drawer writes role / `provider/model` / `provider/*` chains with full selector validation. Writes are AST child-by-child, so a hand-tuned `maxRetries` and its comments survive a chains edit, and the app never deletes retry knobs it does not manage.
- **RPM package** (`OMP-Switch-X.Y.Z-linux.rpm`) alongside AppImage and deb, with build-provenance attestation and coverage in `SHA256SUMS.txt`.
- **DeepInfra** provider preset, and **SiliconFlow split** into international (.com) and CN (.cn) to match OMP 18.2's catalog — the bare `siliconflow` id now means the international site.
- Modeling and validation for OMP v18 model-level fields: `discovery.injectV1` (with a warning when it sits on a discovery type that ignores it), per-model `compactionModel`, and the per-model `thinking` / `thinkingFormat` / `qwenTemplateReasoningEffort` contract. Hand-written values round-trip untouched; invalid ones are caught before commit.

## Changed

- **`designer` role removed** from the role catalog: OMP v18 lists nine built-in roles and `designer` is not one of them — assigning it only wrote a key OMP treats as an unknown custom role. The canonical list now lives in core with a drift test against the UI catalog.
- The provider preset catalog now carries 56 entries.

## Fixed

- **The nightly Windows install regression had never passed** — four stacked bugs since its v0.6.0 introduction: a four-part PE version compared against three-part semver, a `$home` variable colliding with PowerShell's read-only `$HOME`, the installed CLI racing a process the silent installer left behind, and cmd-style `\"` escaping in a pwsh string breaking the apply patch JSON. All fixed; the full install → upgrade → CLI → secret-bridge → uninstall chain is green on every tag and nightly run.

## Security

- No new permissions, network calls, or dependencies. The fallback-chain editor writes only to the user's own config.yml through the same hash-guarded, snapshotted commit path as every other setting.

## Known Limitations

- **Gateway** remains a local feature and requires a configured pool before it can route requests.
- **OAuth integration** continues to depend on each provider's external authentication flow.
- **Session indexing** is local-only and reflects files available beneath the active profile's agent directory.
- **Update checking** requires the release workflow's `OMP_UPDATE_ED25519` secret to upload a signed manifest.
- Qwen Portal is not offered as a preset: it is an OAuth coding-plan provider reached through `omp /login`, with no endpoint a models.yml override could carry.
- winget and Chocolatey manifests ship with this release; upstream review timing is theirs (first Chocolatey submission is moderated).
