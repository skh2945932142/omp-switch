# OMP Switch v0.8.0

**Aligned with Oh My Pi v18.4+ and CC Switch.** This release delivers full alignment with Oh My Pi's latest upstream schema (v18.4+), and absorbs CC Switch's rich provider presets and thinking level mapping architecture. The preset catalog now features over 79 ready-to-use providers with verified model capabilities, reasoning flags, context windows, and `thinkingLevelMap` specifications.

## Added

- **Expanded Provider Preset Catalog (79+ entries)**: Ingests and adapts CC Switch's curated provider presets, adding PPIO AI, Kimi For Coding (national and global), 302.AI, AIHubMix, ShengsuanYun, AICoding, SubRouter, Sub2API, DeepBricks, CherryIN, Apple Foundation Models, and many more.
- **Thinking Profiles & `thinkingLevelMap`**: Introduces first-class support for `thinkingLevelMap` per model, mapping OMP's discrete thinking levels (`off`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`) to downstream provider parameters (OpenAI, Anthropic, DeepSeek, Gemini, Kimi, GLM). Includes curated profiles (`deepseekV4`, `xhighAndMax`, `kimi3`, `geminiLowHigh`, `openaiResponsesGpt5`, etc.).
- **OMP v18.4+ Schema Alignment**:
  - Full support and validation for new provider APIs: `openrouter-decisions` and `typesafe`.
  - New discovery source: `apple-foundation-models`.
  - Model-level fields: `maxContextWindow` (with assertion that `maxContextWindow >= contextWindow`), `supportsTools`, and `promptCache` thresholds (`short`/`long`).
  - Settings fields: `gc.stale` (stale session cleanup) and `tools.artifactMaxBytes`.
- **Technical Specifications**:
  - `docs/pi-contract.md`: Pi native contract, explicit provider synchronization rules, and local security boundaries.
  - `docs/pi-thinking-profiles.md`: Comprehensive thinking level mapping reference and role reasoning integration.

## Changed

- **Version Bump**: Bumped to `0.8.0` across project configurations, Scoop bucket definitions, and Winget packaging templates.
- **Enhanced Validation**: Added thorough diagnostics catching misconfigured `thinkingLevelMap` keys, negative prompt caching token values, and malformed GC / tools settings.

## Security

- Zero telemetry, local-only architecture. API keys remain protected in platform-native secret storage (DPAPI on Windows, libsecret / age on Linux) and are never saved as plaintext in `models.yml` or sent across the network.
