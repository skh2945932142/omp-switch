# OMP Switch v0.8.0

This release follows Oh My Pi's v18.4 config format and adds a bigger provider catalog, with CC Switch's catalog as a reference. The catalog now has 81 presets, and some preset models carry context length, output limit, a reasoning flag, and a `thinkingLevelMap`.

## Added

- **OMP v18.4 config format.** The validator now understands:
  - the `openrouter-decisions` and `typesafe` API types;
  - the `apple-foundation-models` discovery source;
  - `maxContextWindow` (it must be at least `contextWindow`), `supportsTools`, and `promptCache` (`short` / `long`) on models;
  - `gc.stale` and `tools.artifactMaxBytes` in `config.yml`.
- **81 provider presets**, up from 56. New ones include PPIO AI, Kimi For Coding (CN and global), 302.AI, AIHubMix, ShengsuanYun, AICoding, SubRouter, Sub2API, DeepBricks, CherryIN, and Apple Foundation Models.
- **`thinkingLevelMap` on preset models.** It maps OMP's thinking levels to what each provider's API expects, and marks levels a model doesn't support as `null`. 17 preset models have one (OpenAI, Anthropic, Gemini, DeepSeek, Kimi, GLM, Qwen). The profiles live in `packages/core/src/thinking-profiles.ts`.
- **Two new docs:** `docs/pi-contract.md` and `docs/pi-thinking-profiles.md`.

## Changed

- Version bumped to `0.8.0` in `package.json`, the Scoop bucket, and the winget templates.
- More validation diagnostics: bad `thinkingLevelMap` keys or values, negative `promptCache` thresholds, and malformed `gc` / `tools` settings.
- The CI and release workflows now install `rpm` on Linux runners, because building the `.rpm` needs `rpmbuild`.

## Security

- No new permissions, network calls, or dependencies. API keys still stay out of `models.yml`: Windows keeps them under DPAPI, Linux in libsecret (with an age-file fallback), and the config holds only a command that fetches them.

## Known Limitations

- The UI doesn't use `thinkingLevelMap` yet. The map is written into `models.yml` and validated, but the thinking-level control doesn't grey out levels a model doesn't support.
- `gc.stale` and `tools.artifactMaxBytes` are validated and preserved, but you can't edit them in the UI yet.
- Preset data (context windows, output limits, thinking maps) was put together with CC Switch's catalog as the main reference. Providers change these without notice, so check the diff before you save.
- **Gateway** remains a local feature and requires a configured pool before it can route requests.
- **OAuth integration** continues to depend on each provider's external authentication flow.
- **Session indexing** is local-only and reflects files available beneath the active profile's agent directory.
- **Update checking** requires the release workflow's `OMP_UPDATE_ED25519` secret to upload a signed manifest.
- The binaries are not code-signed, so Windows SmartScreen will warn.
- winget carries up to 0.7.0 for now. 0.8.0 is yet to be submitted.
