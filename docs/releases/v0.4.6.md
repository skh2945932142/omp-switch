# OMP Switch v0.4.6

This release is a Quiet Instrument increment: leftover dashboard chrome is removed, list
density and page rhythm are tightened, and empty-state copy is shortened to a title plus one
line. The write path, secret bridge, gateway, and update checker are unchanged.

## Downloads

| `OMP-Switch-Setup-0.4.6.exe` | Windows x64 | NSIS installer, per-user |

The installer and portable build include the Windows DPAPI-backed secret bridge and the packaged
`omp-switch-cli.exe`. The headless CLI image is published as
`ghcr.io/skh2945932142/omp-switch-cli:0.4.6` and `:latest`.

## Changed

- **Dashboard residue removed.** Selected list / session / role rows no longer carry a 3px teal
  inset rail; they use the same Apple Settings soft fill (`--selected` / `--signal-soft`) as the
  nav. Eyebrows, nav groups, palette headings, form-group titles, dropdown labels, picker groups,
  diagnostics groups, and usage table heads drop ALL-CAPS + wide tracking for sentence case.
- **Typography rhythm.** More air between the eyebrow and the 28px page title; workspace padding
  and heading bottom margin open slightly so a module reads as a sheet, not a toolbar glued to a
  title. The count next to a heading is quiet type, not a sunken pill (the nav already has the
  badge). Drawer head height matches the top bar (64px).
- **List density.** Provider card heads 64→52, model rows 56→48, source-list / session rows 60→48,
  role cards and compact empty frames tightened. Expand/collapse, the five-column model grid, and
  the hover edit / quick-assign affordances are unchanged.
- **Empty states.** The sunken + hairline well is gone; the glyph is a quiet icon on the page
  surface. Hint copy is one short line (title + line + CTA). Product explanations no longer live
  in the empty frame.
- Switch thumb and dialog scrim move onto tokens (`--switch-thumb`, `--scrim`). Hardcoded
  `PROFILE` / `ROLES` / `SESSION` / `POOL` / `DIAGNOSTICS` / `PROVIDER` eyebrows are i18n; save
  dialog `REVIEW` / `CONFLICT` / `CONFIRM` / `SHORTCUTS` are sentence case. New keys:
  `providerEditor.provider`, `surfaces.source.*`, `gateway.pool`.

## Feature status

- **Update checking**: implemented (v0.4.4). Ed25519-signed manifest fetched from GitHub,
  signature verified against a hardcoded key, throttled to 24h, silent on failure,
  auto-check on by default with a manual toggle. Only notifies; never auto-downloads or
  installs. Unchanged in this release.
- **Gateway**: experimental, headless only (`--gateway [profile]`), loopback with a
  mandatory bearer token; unchanged.
- **OAuth integration**: passthrough to `omp auth status` / `omp auth login` only; no
  token storage or refresh handling in-app; unchanged.
- **Session indexing**: always on — two-phase incremental refresh backed by the on-disk
  metadata cache; unchanged.

## Known limitations

- Screenshots in `docs/images/` are still v0.4.0-era (3px rail + column drawer) and do not
  match this release's chrome.
- Demo session titles / chat in `createMockApi` stay Chinese: they are fixture content,
  not chrome. `KNOWN_ROLES` keeps its Chinese gloss as a fallback for the export
  contract; the displayed gloss comes from `roles.roleGloss.*`.
- Usage in-row sparkline stays labelled as cost (`usage.dailyTrend`) because that series
  is always `bucketCost`.
- The desktop application is Windows-only because its credential path uses Windows DPAPI.
- The binaries are not code-signed, so SmartScreen can warn on first run.
- Mica requires Windows 11 22H2+ and falls back to solid surfaces elsewhere; the custom
  title bar requires Windows 10+ and falls back to the system frame elsewhere.
- winget and Chocolatey submissions remain pending in their external review queues.
