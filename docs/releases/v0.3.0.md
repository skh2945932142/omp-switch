# OMP Switch v0.3.0

This release packages the current supported OMP Switch surface for Windows desktop use and for the
cross-platform headless JSON CLI. The release pipeline builds the Windows assets on a clean runner,
generates checksums from those exact assets, and records build-provenance attestations.

## Downloads

| Artifact | Platform | Notes |
| --- | --- | --- |
| `OMP-Switch-Setup-0.3.0.exe` | Windows x64 | NSIS installer, per-user |
| `OMP-Switch-0.3.0-win.zip` | Windows x64 | Portable build |
| `SHA256SUMS.txt` | — | SHA256 verification for both artifacts |

The installer and portable build include the Windows DPAPI-backed secret bridge and the packaged
`omp-switch-cli.exe`. The headless CLI image is published as
`ghcr.io/skh2945932142/omp-switch-cli:0.3.0` and `:latest`.

## What is included

- Safe OMP provider, model, role, profile, snapshot, prompt, skill, session, and gateway workflows.
- A stable JSON CLI with `list`, `get`, `validate`, `snapshot`, and `apply` commands.
- Windows DPAPI credential handling through the native secret bridge; API keys are never written to
  OMP configuration files.
- A Scoop manifest synchronized from the checksum of the published portable ZIP.

## Package-manager status

- Scoop is served from this repository and is synchronized after the GitHub Release is published.
- winget manifests are rendered from the published installer hash and submitted to
  `microsoft/winget-pkgs`; availability depends on Microsoft validation and review.
- Chocolatey metadata is rendered into a `.nupkg`; feed publication depends on a Chocolatey API key
  and community moderation.

## Verify what you downloaded

```powershell
(Get-FileHash -Algorithm SHA256 ".\OMP-Switch-Setup-0.3.0.exe").Hash.ToLower()
(Get-FileHash -Algorithm SHA256 ".\OMP-Switch-0.3.0-win.zip").Hash.ToLower()
# Compare both values with SHA256SUMS.txt.
gh attestation verify ".\OMP-Switch-Setup-0.3.0.exe" --repo skh2945932142/omp-switch
```

## Known limitations

- The desktop application is Windows-only because its credential path uses Windows DPAPI.
- The binaries are not code-signed, so SmartScreen can warn on first run.
- Clean-Windows install, upgrade, and uninstall regression remains pending.
- winget and Chocolatey may remain pending while their external review queues process the submission.
